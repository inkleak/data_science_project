# Data Science Project
A 5 week long passion project, creating a data analysis platform for looking at player performance in a given league, team or position. This is a collaborative project.

## Where is our data from?

As of 19/01/26, the data set is from Kaggle. The link can be found here: https://www.kaggle.com/datasets/orkunaktas/premier-league-all-players-stats-2324

Originally, a data set from FootyStats was to be used. However this data set was scrapped due to significant amounts of missing data. Potentially later on we will revisit this.

## Update Log
